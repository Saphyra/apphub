ListItem
pk: USER#userId
sk: LIST_ITEM#listItemId
parent: LIST_ITEM#listItemId
type: ListItemType
title: listItemTitle
pinned: boolean
archived: boolean
data: storedFileId/url

GSI_PARENT (Get children of a parent)
pk: USER#userId
sk: parent

Content
pk: LIST_ITEM#listItemId
sk: CONTENT#batchIndex
content: Map<contentId, text> //Serialised to JSON string and encrypted

Lookup content: Query all, filter by contentId
Save content:
    New: batchId null, split to batches if size too large
    Extend: add batchId=null items to existing batches, create new batches if needed
    Edit: delete text from existing batch, and handle it as extend. Mark original content as modified, so by re-save old value is deleted
    Delete: delete text from existing batch, and mark it as modified
