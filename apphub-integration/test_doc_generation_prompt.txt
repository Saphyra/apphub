Add a Javadoc for every testCase
Javadoc should contain
1. a summary / description what the test case tests / does / covers
2. the list of sub-cases (if the test consists more than one case)

Example sub-cases:
"validate endpoint {endpoint name or method + url} returns {response} when called with {incorrect data}"
"Error message appears when user clicks on {button}"
"{what happens} when {action} is performed with by the user"

Add the javadoc only to the method(s) annotated with @Test
Put the javadoc above the method's annotations
Line length limit is 160 characters, don't break lines in the middle of a sentence if the sentence is shorter
Use ul and li html tags for each sub-case in the list

After modifications are done, verify if Javadoc is added to all the selected files' test cases, and if any test case is missing Javadoc, add it accordingly.
